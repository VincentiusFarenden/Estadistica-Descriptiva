# Estadística Descriptiva

Conjunto de ejercicios en Jupyter Notebook sobre estadística descriptiva con Python.

## Contenido

- Medidas de tendencia central (media, mediana, moda)
- Medidas de dispersión (varianza, desviación estándar)
- Análisis de distribuciones
- Visualización de datos estadísticos
- Tablas de frecuencia
- Probabilidad y azar
- Modelos de regresión lineal
- Distribución normal de probabilidad
- Medidas de asociación
- Coeficiente de determinación

## Instalación

Clona el repositorio:
```bash
git clone https://github.com/VincentiusFarenden/Estadistica-Descriptiva.git
cd Estadistica-Descriptiva
```

Instala las dependencias en un entorno virtual (Para no romper otros paquetes nativos del sistema):

*Nota: Si utilizas Google Colab no es necesario instalar las dependencias ya que vienen pre-instaladas en la instancia por defecto.*

Linux/MacOS
```bash
python3 -m venv ~/venvs/data && ~/venvs/data/bin/pip install --upgrade pip && ~/venvs/data/bin/pip install numpy pandas matplotlib scipy scikit-learn jupyter
```
Windows (PowerShell)
```bash
python -m venv $HOME\venvs\data ; & "$HOME\venvs\data\Scripts\pip" install --upgrade pip ; & "$HOME\venvs\data\Scripts\pip" install numpy pandas matplotlib scipy scikit-learn jupyter
```

## Uso

Abre los notebooks (.ipynb) en VS Code o Google Colab y ejecuta las celdas para ver los ejercicios y resultados.

## Librerías utilizadas

- NumPy
- Pandas
- Matplotlib
- SciPy
- Scikit-Learn
